# Guides

Everything we learned getting a full streaming setup to work on Linux, in the order you will
need it. Each guide says what tuxcast automates and how to do it by hand.

| Guide | Read it when |
| --- | --- |
| [Streaming on Linux in 2026](streaming-on-linux.md) | You are setting up, or switching from Windows |
| [OBS on Linux](obs.md) | Choosing an encoder, capturing games and screens, multistreaming |
| [Stream Deck on Linux](stream-deck.md) | You own a Stream Deck |
| [Audio routing](audio.md) | You want the music out of your VODs, or Discord on its own fader |
| [Discord and Spotify in sandboxes](sandboxes.md) | A Stream Deck key or media key does nothing |
| [Music without claims](music.md) | You play music on stream |
| [Network](network.md) | Twitch says your connection is unstable |

Something missing for your desktop, GPU or distribution? Guides are Markdown files in
[`docs/guides/`](https://github.com/achedon12/tuxcast/tree/main/docs/guides): pull requests welcome.
