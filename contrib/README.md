# contrib

Ready-made files for tuxcast and for people who prefer to set things up by hand.

| File | What it is |
| --- | --- |
| [`patches/twitch-oauth-port.toml`](patches/twitch-oauth-port.toml) | A [`tuxcast patch`](https://achedon12.github.io/tuxcast/commands/patch/) moving StreamController's Twitch login off port 3000 |
| [`udev/70-streamdeck.rules`](udev/70-streamdeck.rules) | The udev rule giving your user access to Elgato devices |

Have a patch that fixes an app for everyone? Add it here with a comment explaining why, and
open a pull request.
